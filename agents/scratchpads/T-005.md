## Patch summary
- Updated `PlotSpec`, `XAxisSpec`, and `YAxisSpec` to reject unknown keys (`extra="forbid"`).
- Added validators for:
  - `scale` values (`linear` or `log`, normalized to lowercase)
  - `range` shape/order (`[min, max]` with `min < max`)
  - non-empty `y` axis list and non-empty per-axis `signals` mapping.
- Improved validation diagnostics:
  - `from_yaml` now reports syntax errors as `Invalid YAML syntax: ...`
  - `ValidationError` details are formatted with explicit field paths (for example, `y.0.scale`)
  - `from_file` wraps validation errors with the config file path context.
- Expanded unit coverage in `tests/unit/plotspec/test_plotspec_basic.py` for strict schema and diagnostics.
